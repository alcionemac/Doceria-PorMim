# 🍰 Doceria Por Mim

Projeto de site desenvolvido para apresentar uma doceria, com foco em exibição de produtos, identidade visual e experiência do usuário.

---

## 📌 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de praticar e consolidar conhecimentos em desenvolvimento web, utilizando HTML e CSS para criação de uma interface visual agradável e organizada.

A proposta é simular o site de uma doceria, exibindo banners, galeria de imagens e estrutura básica de navegação.

---

## 🚀 Tecnologias utilizadas

* HTML5
* CSS3

---

## 🎨 Funcionalidades

* Layout visual de uma doceria
* Exibição de banners
* Galeria de imagens
* Estrutura organizada de páginas
